# Personal Developer Portfolio 🚀

A modern, minimalist, and fully responsive personal portfolio website to showcase my projects, skills, and academic journey.

---

## 🔗 Live Demo

- **Live Site**: [https://rahul01.vercel.app/](https://rahul01.vercel.app/) *(or update with your live deployment URL)*
- **GitHub Repository**: [https://github.com/rahulchoudhary9593/Rahul01](https://github.com/rahulchoudhary9593/Rahul01)

---

## ✨ Key Features

- **🌓 Dark & Light Mode**: Built-in theme toggle with custom CSS variables and smooth transitions.
- **📱 Fully Responsive**: Mobile-first design ensuring clean and optimal layouts across mobile, tablet, and desktop screens.
- **✨ Smooth Animations**: Custom typing effects, subtle hover interactions, and scroll-reveal animations for an engaging UX.
- **📬 Working Contact Form**: Integrated with Google Sheets (via Google Forms) for seamless, zero-page-reload message delivery.
- **📄 Resume Integration**: One-click viewing and downloading capabilities for your latest CV/Resume.
- **⚡ High Performance & SEO Friendly**: Semantic HTML5 structure with optimized meta and Open Graph tags.

---

## 🛠️ Tech Stack

- **Markup**: HTML5
- **Styling**: CSS3 (Flexbox, CSS Grid, Media Queries, CSS Custom Properties / Variables)
- **Interactivity**: Vanilla JavaScript (ES6+)
- **Assets & Typography**: Google Fonts (Inter / Manrope / Poppins), Vector Icons & Favicons

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/rahulchoudhary9593/Rahul01.git
```

### 2. Navigate into the project folder
```bash
cd Rahul01
```

### 3. Open in Browser
- Simply double-click `index.html` to open it in your default web browser, or
- Use VS Code extension **Live Server**: right-click `index.html` and select **"Open with Live Server"**.

## 🌐 Deployment

You can deploy this site for free on:
- **Vercel**: Import your GitHub repository into [Vercel](https://vercel.com/) and click **Deploy**.
- **GitHub Pages**: Go to repository **Settings** → **Pages** → select `main` branch → **Save**.
- **Netlify**: Drag and drop the folder or connect your Git repo on [Netlify](https://www.netlify.com/).
